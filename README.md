<h1>Ferroviaria - Aplicación Web</h1>
Descripción
Ferroviaria es una aplicación web diseñada para alumno interesados en ingenieria ferroviaria enfocados en espcialmente alumnos de UPIICSA

La aplicación está alojada en Firebase y accesible públicamente en: https://ferroviaria-d3c53.web.app/

Características principales

*Informacion del plan de estudio de UPIICSA <br>
*Historia <br>
*Componentes <br>
*Modelo 3D <br>
*Oportunidades Laborales <br>

<h2>Tecnologías utilizadas</h2>
Frontend: HTML,CSS.

Backend: Firebase/Node.js/JavaScript/Vite.

Alojamiento: Firebase Hosting

Otras librerías: ScrollReveval, Three.js.
